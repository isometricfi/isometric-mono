# Isometric

Isometric 是一个比特币看涨期权应用。

市场有两端。

如果你持有 BTC 并想**赚取收益**，你可以写一个报价。设定一个 BTC 必须保持低于的价格，买方接受时立即获得一笔金额。如果到期时 BTC 高于你的行权价，你需要从你的 BTC 中支付差额。

如果你想要 BTC 的**杠杆押注**，你可以买入。投入少量金额获得大得多的 BTC 头寸敞口，期限固定。如果到期时 BTC 高于你选定的价格，你保留上行收益。如果没到，你失去投入的金额。

## 工作原理概览

1. 连接钱包并设置账户。
2. 存入 BTC。
3. 写报价或买期权。
4. 到期时自动结算。
5. 余额可用时随时把 BTC 提取到任何地址。
