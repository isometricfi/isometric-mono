# 期权说明

看涨期权是一种权利（不是义务），让你在选定日期前 BTC 涨破选定价格时获利。

每个期权都有两端：

- **买方**预先支付一笔金额。如果到期时 BTC 高于行权价，买方以 BTC 形式获得差额。如果 BTC 等于或低于行权价，买方失去投入的金额。
- **卖方**投入 BTC 并获得买方的支付。如果 BTC 等于或低于行权价，卖方保留全部资金。如果 BTC 高于行权价，差额从卖方的 BTC 中扣除。

Isometric 仅支持看涨期权。

## 完全有担保：Isometric 的不同之处

大多数期权交易场所运行在保证金机制上。卖方提供仓位的一部分作为保证金，价格不利时会被强制平仓。这里不是这样。

在 Isometric 上，每个期权在被接受时由真实 BTC **完全担保**。卖方最差的情况是支付收盘价超出行权价的部分，最大不超过投入的 BTC。没有保证金追缴，没有强制平仓，没有强制收盘。期权一旦被接受，结果完全由收盘价决定。

- 买方最多损失投入的金额。
- 卖方最多损失投入的 BTC。

## 简单示例

BTC 当前 $100,000，一周看涨期权，行权价 $110,000。

- BTC 收盘 $105,000 → 期权失效。买方失去投入的金额。卖方保留全部。
- BTC 收盘 $115,000 → 买方以 BTC 形式获得 $5,000 等值。
- BTC 收盘 $200,000 → 买方获得行权价以上的全部涨幅，最大不超过卖方的抵押品。

卖方的结果是镜像。每种情况下他们都保留权利金，仅当 BTC 收盘高于行权价时才从抵押品中支付。
