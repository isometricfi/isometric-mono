# 存入 BTC

两种存款方式：

- **从已连接的钱包发送。** 存款面板可以直接从你登录所用的钱包发送 BTC。
- **从其他钱包发送。** 每个账户都有一个唯一的 BTC 存款地址。从存款面板复制该地址，然后从任何钱包向其发送。

应用会自动监听你的地址。

## 确认次数

比特币存款需要 **4 次网络确认**。通常约 40 分钟。等待期间，存款面板显示实时确认次数。你可以关闭应用。存款会在后台继续确认。

## 最低存款

**₿0.00002**（2k sats）。建议至少存入 **₿0.00051**（51k sats），因为最低提取金额为 **₿0.000501**（50.1k sats）。

## 可用余额与累计存款

你的余额由两个数字组成：

- **累计存款**：你存入的 BTC 总额。
- **可用**：你现在可以使用的 BTC（写报价、买期权或提取）。

写报价**不会**减少你的可用余额。可用余额仅在买方**接受**你的报价时才下降（此时期权变为活跃，进入持仓）。在那一刻，对应数量的 BTC 进入锁定状态，买方支付的权利金会立即记入你的可用余额。
