# Isometric 如何使用 ICP

Isometric 作为智能合约运行在互联网计算机上。没有链下服务器。协议在阈值 ECDSA 托管下持有 BTC，从链上预言机获取价格，并按自己控制的时间表结算期权。

互联网计算机的三个特性使这种设计成为可能：

1. **阈值 ECDSA。** 互联网计算机的节点协同签署比特币交易。单个节点不持有密钥。这使得无需中心化跨链桥的自我托管成为可能。
2. **共识下的 HTTPS 出站调用。** 智能合约可以获取外部数据，结果由多个节点达成共识。协议的 BTC/USD 预言机就是这样工作的。
3. **自调度智能合约。** 协议可以为自己安排固定间隔的运行，由协议自身支付成本。结算自动运行，无需链下触发，无需运维干预。
