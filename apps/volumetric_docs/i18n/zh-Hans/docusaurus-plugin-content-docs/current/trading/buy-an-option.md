# 买期权

买期权让你在固定期限内获得 BTC 的杠杆上行收益。最大亏损就是你投入的金额。

## 购买流程

应用会引导你完成三个步骤。

### 1. 选择期限和 BTC 应该涨破的价格

选择**期限**和**行权价**（高于当前 BTC 价格的百分比）。在你确认的那一刻，行权价锁定为具体的美元数额。

通常更高的行权价更便宜，杠杆也更高，因为 BTC 触及它们的概率更小。更低的行权价更贵，但更可能获利。详见[写还是买](/strategies/write-or-buy)。

### 2. 选择投入金额

设置你想投入的**金额**。应用会显示对应的**杠杆**。

这个金额就是你的最大亏损。你不会损失更多。

应用会自动选择符合你的行权价和期限的最佳报价。你可以全额接受，也可以接受其中一部分。

### 3. 确认下单

确认页显示行权价、期限、金额、杠杆、最大利润和利润手续费。滑动确认并在钱包中签名。

## 之后会发生什么

期权出现在**持仓 → 活跃**中。到期时自动结算。

到期时间会对齐到整点。在 12:01 接受的 7 天期权，将在七天后的 13:00 到期。

- BTC 收盘**高于**行权价：利润以 BTC 形式结算到你的账户。
- BTC 收盘**等于或低于**行权价：期权失效。你失去投入的金额。

到期时无需签署任何东西。

## 限额

最低购买：**500 sats**（0.000005 BTC）。

## 实例

BTC 当前 $100,000，你在一份 **7 天**、**+10% 行权价**的看涨期权上投入 **0.1 BTC**，相当于在投入金额上获得**约 67 倍杠杆**。

- 行权价锁定在 $110,000。
- 最大亏损：0.1 BTC。
- 到期保本价：$111,675。

| 到期 BTC 价格 | 结果 | 你的净收益 |
|---|---|---|
| $95,000 | 期权失效 | **−0.1 BTC** |
| $111,675 | 保本 | **0.00 BTC** |
| $115,000 | 触发支付 | **+0.19 BTC** |
| $130,000 | 触发支付 | **+0.93 BTC** |
| $200,000 | 大幅上涨，支付接近上限 | **+2.9 BTC** |

行权价以上涨幅越大，支付额越大。低于行权价时，亏损固定为你投入的金额。利润需扣除[20% 平台手续费](/trading/fees)。
