# 结算

到期时，每个期权自动结算。你不需要签署任何东西，也不需要触发任何操作。

## 到期时发生什么

应用从链上预言机读取 BTC/USD 价格，并与期权的行权价比较。

- **BTC 等于或低于行权价**：卖方锁定的 BTC 解锁回到可用余额。买方的期权失效。
- **BTC 高于行权价**：根据 BTC 涨破行权价的幅度计算买方的利润（以 BTC 计）。平台扣除利润手续费。买方收到净支付。卖方剩余的 BTC 解锁。

买方的支付额上限为卖方的抵押品。卖方损失永远不会超过他们投入的 BTC。

## 到期时间如何确定

所有期权都在整点结算。计时从买方接受后的下一个整点开始，因此在 12:01 被接受的 7 天期权，将在七天后的 13:00 到期。这样可以让所有同时到期的期权在同一批次内高效结算。

## 你会看到什么

- 临近到期的仓位会在**持仓 → 活跃**中显示倒计时。
- 一旦到期，会显示**已到期：正在结算...**直到支付完成。
- 结算后，从活跃中消失，并出现在**历史记录**中显示最终结果。
