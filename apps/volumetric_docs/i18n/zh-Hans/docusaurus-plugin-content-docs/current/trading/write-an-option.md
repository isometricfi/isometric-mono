# 写期权

写期权让你预先获得一笔 BTC 收入。你挑选一个 BTC 在所选窗口内必须保持低于的价格目标。如果到期时 BTC 处于该行权价或以下，你保留全部抵押品和权利金。如果 BTC 收盘高于行权价，你按超出行权价的百分比，从你的抵押品中以 BTC 形式支付给买方。

在剧烈上涨（BTC 远超行权价）时，最差的情况是失去你投入的全部抵押品。该结果罕见但可能发生，这正是你预先获得权利金作为补偿的原因。

## 写报价流程

应用会引导你完成四个步骤。

### 1. 选择期限和 BTC 应该保持低于的价格

选择**期限**和**行权价**（高于当前 BTC 价格的百分比）。

行权价百分比在买方接受的那一刻使用当时的 BTC/USD 价格转换为具体的美元价格。

通常更高的行权价更安全，收益也更少；更低的行权价收益更多，但更容易被触及。详见[写还是买](/strategies/write-or-buy)。

### 2. 设置数量

选择用多少 BTC 来支持这个报价。这是你的最大风险敞口。

报价可以由多个买方分批成交。1 BTC 报价可能被分成两次成交，每次按比例把权利金记入你的余额。任何未成交部分都可随时取消。

### 3. 设置权利金

选择你想收取的权利金，以报价金额的百分比表示。应用会显示对应的年化收益率，以及你的报价相对于同行权价、同期限其他公开报价的**竞争力**。

权利金越低成交越快。权利金越高每次成交收入越多，但可能根本不会成交。

### 4. 确认下单

确认页显示行权价、期限、数量、权利金、年化收益率、竞争力和平台手续费。滑动确认并在钱包中签名。

## 限额

- 最低报价数量：**0.0004 BTC**（40,000 sats）。
- 最大报价数量：**1 BTC**。
- 每个期限最多 5 个公开报价。

## 之后会发生什么

报价上线后出现在**持仓 → 报价**中。创建报价**不会**锁定你的 BTC。

当买方接受时（全部或部分）：

- 被接受的 BTC 数量从**可用**转入**锁定**。
- 权利金立即记入你的**可用**余额。
- 被接受的部分作为已写期权出现在**持仓 → 活跃**中。剩余未成交部分仍留在**持仓 → 报价**中。

到期时，期权自动结算。到期时间会对齐到整点：在 12:01 被接受的 7 天报价，将在七天后的 13:00 到期。

- BTC 收盘**等于或低于**行权价：你锁定的 BTC 解锁。你保留权利金和全部抵押品。
- BTC 收盘**高于**行权价：买方利润从你锁定的 BTC 中支付。剩余部分解锁回到你账户。你仍然保留权利金。

## 实例

你以 **+10% 行权价**和 **7 天期限**写 **1 BTC**，**权利金 2%**。BTC 当前 $100,000，买方完全接受。

- 行权价锁定在 $110,000。
- 你的 0.02 BTC 权利金立即到账。
- 1 BTC 进入锁定状态。

| 到期 BTC 价格 | 高于行权价 % | 你的最终持仓 |
|---|---|---|
| $90,000 | 不适用（低于） | 1 BTC + 0.02 权利金 = **1.02 BTC** |
| $110,000 | 0% | 1 BTC + 0.02 权利金 = **1.02 BTC** |
| $111,100 | 1% | 约 0.99 BTC + 0.02 权利金 = **约 1.01 BTC** |
| $200,000 | 82% | 约 0 BTC + 0.02 权利金 = **约 0.02 BTC** |

BTC 涨破行权价的幅度越大，买方拿走你的抵押品越多。你始终保留权利金。
