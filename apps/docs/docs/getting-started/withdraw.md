# Withdraw BTC

You can withdraw your **Available** balance to any Bitcoin address at any time. BTC locked in active options can't be withdrawn.

## How to withdraw

1. Open **Account → Withdraw**.
2. Enter the destination Bitcoin address.
3. Enter the amount.
4. Sign the message in your wallet.

## Minimum withdrawal

**0.0005 BTC** (50,000 sats).

## Bitcoin network fee

A Bitcoin network fee is deducted from the amount you withdraw.

## Timing

Withdrawals submit immediately. It can take up to a minute for the Bitcoin transaction to broadcast, after which it confirms on the Bitcoin network in the usual blocks. You can leave the app while it processes.
