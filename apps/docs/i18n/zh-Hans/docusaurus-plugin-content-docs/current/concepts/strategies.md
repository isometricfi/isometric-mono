# 期权策略

根据您的市场看法和风险承受能力，学习如何有效地使用期权。

## 备兑看涨期权策略 (Covered Call Strategy)

Isometric 使用**备兑看涨期权**，这意味着卖方必须用 BTC **足额抵押**其头寸。

### 运作方式

1. **卖方存入 BTC** 作为抵押品
2. **买方支付权利金**给卖方
3. **到期时**：
   - 如果为**虚值 (OTM)**：卖方保留抵押品 + 权利金
   - 如果为**实值 (ITM)**：买方从卖方的抵押品中获得收益

### 为什么叫“备兑”？

卖方的头寸被实际的 BTC 抵押品**备兑**（覆盖）。这消除了：
- **强平风险**：没有保证金通知
- **对手方风险**：智能合约持有抵押品
- **无限亏损风险**：卖方的损失被限定在抵押品金额内

### 卖方视角

**目标**：在持有的比特币上赚取权利金收入

**最佳情况**：BTC 保持在行权价以下，保留抵押品 + 权利金

**最坏情况**：BTC 大涨超过行权价，损失部分抵押品但保留权利金

**示例：**
- 抵押品：1.0 BTC
- 行权价：$110k (当前 BTC $100k)
- 权利金：0.01 BTC
- **如果到期时 BTC = $105k**：保留 1.0 BTC + 0.01 BTC = **1.01 BTC** ✅
- **如果到期时 BTC = $132k**：支付约 0.167 BTC 收益，保留 0.833 BTC + 0.01 BTC = **0.843 BTC**

### 买方视角

**目标**：获得对比特币价格上涨的杠杆敞口

**最佳情况**：BTC 远高于行权价，获得巨额收益

**最坏情况**：BTC 保持在行权价以下，损失权利金

**示例：**
- 权利金：0.01 BTC (约 $1,000)
- 行权价：$110k
- 数量：1.0 BTC
- **如果到期时 BTC = $105k**：损失 0.01 BTC ❌
- **如果到期时 BTC = $132k**：收到约 0.167 BTC (约 $22,000)，净利润约 $21,000 ✅

## 风险与回报概况

### 对于买方

| 指标 | 数值 |
|--------|-------|
| **最大损失** | 支付的权利金 |
| **最大收益** | 理论上无限（随 BTC 上涨） |
| **损益平衡点** | 行权价 + 权利金 (以美元计) |
| **风险等级** | 有限下行，无限上行 |

**核心提示**：您的风险**始终被限定**在预先支付的权利金内。

### 对于卖方

| 指标 | 数值 |
|--------|-------|
| **最大损失** | 抵押品 - 权利金 (如果 BTC 趋于无限) |
| **最大收益** | 赚取的权利金 |
| **损益平衡点** | 行权价 |
| **风险等级** | 有限上行，下行风险较大 |

**核心提示**：您的收益被限定在权利金内，但如果 BTC 大涨，您将承担放弃上涨空间的风险。

## 什么时候使用期权

### 当出现以下情况时买入看涨期权：

- 您**看涨** BTC (预期价格会上涨)
- 您想要**杠杆敞口**而无需买入足额 BTC
- 您希望**限定下行风险** (仅损失权利金)
- 您预期会有**高波动性** (价格剧烈波动)

### 当出现以下情况时卖出看涨期权：

- 您对 BTC 持**中性到轻微看涨**态度
- 您想在持有的 BTC 上**赚取收益**
- 您愿意在行权价处**封顶您的上行收益**
- 您预期**低波动性** (价格相对平稳)

## 给买方的建议

1. **了解您的最大损失** - 绝不要投入超过您能承受损失的资金
2. **仔细选择行权价** - 行权价越高，权利金越低，但需要 BTC 更大的涨幅
3. **考虑剩余时间** - 离到期时间越长，BTC 就有越多时间波动
4. **关注波动性** - 高波动性意味着权利金更高，但潜在利润也更大
5. **保持耐心** - 在到期前的最后几个小时，期权仍有可能发生剧烈变动

## 给卖方的建议

1. **从小额开始** - 先在小额持仓上进行测试
2. **选择现实的行权价** - 虚值太远收益太低，行权价太近风险太高
3. **监控市场** - 根据 BTC 波动性调整您的挂单
4. **分散到期日** - 不要把所有抵押品都放在同一个到期日
5. **了解您的风险** - 您在行权价上方封顶了您的上行空间

## 常见误区

### “期权风险太大”

**事实**：对于买方来说，风险被**限定在权利金内**。这可能比直接买入 BTC 的风险更小。

### “我需要手动行使期权”

**事实**：在 Isometric 上，结算是**完全自动的**。您无需进行任何操作。

### “作为买方，我的损失可能超过权利金”

**事实**：**错误**。买方的损失永远不会超过预先支付的权利金。

### “卖方承担无限风险”

**事实**：在 Isometric 上，卖方使用**备兑看涨期权**，因此风险被限定在抵押品金额内。
