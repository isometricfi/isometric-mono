# 写还是买

同一市场下的两条路径。双方都在对到期时 BTC 的位置下注。

## 写——为承担风险而获取收入

写期权预先付钱给你，因为你同意在 BTC 涨破行权价时支付。你实际上是在赌 BTC 在该期限内会保持低于行权价。如果你赌对了，你保留权利金和抵押品。

市场根据行权价被触及的可能性来定价权利金。+5% 行权价、1 天期限不太可能达到，所以权利金小。+5% 行权价、14 天期限有更多时间移动，所以卖方需要更高的权利金来补偿这个风险。同样的行权价，不同的风险，不同的价格。

## 买——支付一笔为换取非对称押注

买期权预先支付一个已知金额，换取 BTC 涨破行权价时不设上限的上行收益。你在赌 BTC 会在期限结束前涨破行权价。如果赌对了，支付额随涨幅扩大。如果没有，你只损失投入的金额。

便宜的权利金看起来很有吸引力，但反映的是市场认为该行权价不太可能被触及的看法。昂贵的权利金往往出现在期限较短、行权价较近的情境——这些情境下到达行权价更有可能。便宜期权的杠杆之所以高，正是因为该走势不太可能发生。

## 双方在为同一件事定价

买方和卖方都在对"到期时 BTC 是否高于行权价"的概率发表观点。权利金就是市场对这个概率达成的价格：

- 期限越长，BTC 移动的时间越多 → 权利金越高。
- 行权价越近，越容易被触及 → 权利金越高。
- 近期波动越剧烈 → 整体权利金越高。

写期权时，你在承担别人押注的对手方。买期权时，你在付钱让别人承担你押注的对手方。多数活跃交易者两边都做，根据当时的观点选择。
