# 提取 BTC

你可以随时把**可用**余额提取到任何比特币地址。锁定在活跃期权中的 BTC 不能提取。

## 如何提取

1. 打开**账户 → 提取**。
2. 输入目标比特币地址。
3. 输入金额。
4. 在钱包中签署消息。

## 最低提取

**0.0005 BTC**（50,000 sats）。

## 比特币网络费

比特币网络费会从你提取的金额中扣除。

## 时效

提取请求会立即提交。比特币交易最长可能需要约一分钟才广播到网络上，之后按通常的区块速度确认。处理过程中你可以离开应用。
