# 连接与账户

Isometric 使用你已有的钱包进行签名。无需另外设置密码。

## 连接钱包

1. 打开应用并点击**连接**。
2. 选择钱包并批准连接。
3. 应用会为你创建 Isometric 账户。

## 设置账户

首次连接时，应用会请求你签署消息以证明账户归属。

## 用户名

在**账户**面板中选择用户名。用户名是公开的，会出现在分享的持仓和交易链接中。你可以随时更改。

## 邀请码

如果有朋友推荐了你，在设置时粘贴他们的邀请码。账户激活后，可以在账户面板的**邀请用户**中找到自己的邀请链接。
