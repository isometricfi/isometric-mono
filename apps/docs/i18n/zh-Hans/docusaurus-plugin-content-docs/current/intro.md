# 欢迎来到 Isometric

**Isometric** 是一个构建在 [Internet Computer 协议 (ICP)](https://internetcomputer.org/) 之上的去中心化期权交易平台。提供透明的定价、自动结算和全链执行的比特币期权交易。

## 什么是 Isometric？

Isometric 使您能够在完全去中心化的环境中交易比特币**期权**。与传统的期权平台不同：

- **去中心化**：所有交易通过 ICP 智能合约在链上执行
- **透明**：可验证的结算和实时预言机定价
- **比特币原生**：以比特币进行抵押和支付
- **自动结算**：期权在到期时自动结算
- **无对手方风险**：智能合约持有抵押品并强制执行结算

## Isometric 为谁而建？

### 期权卖方 (Writers)

通过在您的比特币持仓上卖出备兑看涨期权（covered calls）来赚取权利金。将您的 BTC 作为抵押品锁定，并从买方那里收取权利金。

[了解如何卖出期权 →](/quick-start/write)

### 期权买方 (Buyers)

通过购买看涨期权获得对比特币价格波动的杠杆敞口。预先支付权利金，以获得在 BTC 上涨超过行权价时获利的权利。

[了解如何买入期权 →](/quick-start/buy)

## 核心特性

### 标准化合约

期权合约在行权价间隔、权利金水平和到期时间上都是标准化的。这创造了深度流动性，并使寻找对手方变得容易。

### 备兑看涨期权 (Covered Calls)

当前版本仅支持**备兑看涨期权**。卖方必须用 BTC 足额抵押其头寸。这消除了爆仓风险并保持了系统的简洁性。

### 自动结算

当期权到期时，平台会自动：
1. 从 ICP 预言机获取 BTC/USD 价格
2. 计算实值期权的收益
3. 将利润转给买方，并将剩余抵押品退还给卖方

无需手动行权。
