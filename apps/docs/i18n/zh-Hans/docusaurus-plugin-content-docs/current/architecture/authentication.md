# 身份验证与安全

Isometric 旨在为用户提供类似于中心化交易所的体验，同时保持去中心化应用（dApp）的所有非托管安全优势。

## 非托管身份验证

Isometric 本身不需要传统的用户名或密码。相反，您的身份与您在 Internet Computer (IC) 上的 **Principal ID** 绑定。

我们支持三种主要的连接方式：
- **Internet Identity**：利用生物识别（触控 ID、面容 ID）或硬件安全密钥，提供最高级别的隐私和便利性。
- **Bitfinity & Plug Wallet**：适用于希望使用典型浏览器扩展钱包界面的高级用户。
- **NFID**：为用户提供单点登录体验。

## 基于签名的交易授权

在平台上进行关键操作（如创建订单、取消订单或提款）时，用户必须对其操作进行加密签名。

1. **客户端签名**：您的私钥从未离开过您的本地环境或硬件设备。
2. **链上验证**：Isometric 容器智能合约接收签名，并根据用户的 Principal 验证其合法性。
3. **不可否认性**：一旦签名并广播，该操作即被视为权威操作。

## 会话管理

为了提供更流畅的交互界面（避免频繁的弹出签名窗口），Isometric 对基础数据加载和只读查询采用匿名或半持久化会话。但所有涉及 ckBTC 资金移动的操作始终需要显式授权。

## 安全特性

- **冷热钱包隔离**：大部分用户资金被锁定在高度安全的 ckBTC 账本中。
- **受控管理权限**：敏感配置（如费用比例或预言机源）由管理员组控制，未来计划过渡到去中心化治理（DAO）。
- **实时审计**：所有订单创建和成功的结算都作为不可变事件记录在链上。

## 最佳实践

1. **保护您的助记词**：由于 Isometric 是非托管的，一旦您丢失了钱包访问权限，团队无法帮您找回资金。
2. **验证域名**：始终确保您在 `isometric.fi` 的正确官方子域下运行，以防钓鱼攻击。
3. **小额测试**：在进行大额比特币期权交易前，先用小额 ckBTC 熟悉所有操作流程。
