# 费用结构

Isometric 收取极低比例的服务费，以维持平台的后续开发和日常运营成本。本篇详细说明了目前的各项费用细则。

## 费用类型

### 1. 权利金手续费 (Premium Fee)

当买方接受卖方的报价时产生。

**比例**：权利金的 5% (可配置调节)

**示例**：
- 期权权利金：0.01 BTC
- 权利金手续费：0.0005 BTC (5%)
- 卖方实收：0.0095 BTC
- 平台账户收取：0.0005 BTC

**由谁支付**：买方承担 (已计入购买时支付的总成本中)。

### 2. 利润分成费 (Profit Fee)

仅当期权到期为实值（ITM）且产出盈利时扣除。

**比例**：买方盈利部分的 20% (可配置调节)

**示例**：
- 理论赔付总额：0.05 BTC
- 利润手续费：0.01 BTC (20%)
- 买方实收：0.04 BTC
- 平台账户收取：0.01 BTC

**由谁支付**：由买方支付 (自动从结算赔付总额中扣除)。

### 3. ckBTC 网络转账费 (ckBTC Transfer Fees)

由 ckBTC 账本（ledger）层收取的固定费用，并非由 Isometric 平台直接收取。

**比例**：每次转账约 0.0000001 BTC

**涉及场景**：
- 权利金支付转账。
- 手续费归集转账。
- 从平台提款到外部钱包。

**由谁支付**：发起特定链上动作的用户。

## 费用配置

平台管理员可以通过以下后台接口更新费用参数：

```rust
pub struct FeeConfig {
    pub premium_fee_basis_points: u64,  // 示例：500 代表 5%
    pub profit_fee_basis_points: u64,   // 示例：2000 代表 20%
}
```

后台更新指令示例：

```bash
dfx canister call isometric_dev set_fee_config --network ic '(record {
  premium_fee_basis_points = 500 : nat64;
  profit_fee_basis_points = 2000 : nat64;
})'
```

## 费用示例汇总

### 场景：买方（Buy 0.5 BTC 期权，权利金 1%）

- 标的权利金：0.005 BTC
- 权利金手续费 (5%)：0.00025 BTC
- 网络转账费：~0.0000002 BTC
- **购买总支出**：约 0.00525 BTC

**结算时** (假设实值 ITM)：
- 总赔付额：0.08 BTC
- 利润分成费 (20%)：0.016 BTC
- **到账纯收益**：0.064 BTC

**净利润**：0.064 - 0.00525 = **0.05875 BTC**

### 场景：卖方（Write 0.5 BTC 期权，权利金 1%）

- 预期权利金收益：0.005 BTC
- 权利金手续费支出 (5%)：-0.00025 BTC
- **净赚权利金**：0.00475 BTC

**结算时** (假设虚值 OTM)：
- 原路退还抵押品：0.5 BTC
- **累计总资产**：0.50475 BTC (本金 + 权利金净收益)

**结算时** (假设实值 ITM)：
- 赔付给买方：0.08 BTC
- 剩余退还本金：0.42 BTC
- **累计总资产**：0.42475 BTC (剩余本金 + 权利金净收益)
