# 风险

你可能损失什么，以及如何损失。交易前请阅读本节。

## 买方风险

你的最大亏损**正好是你投入的金额**。如果到期时 BTC 等于或低于行权价，期权失效，你将失去所支付金额的 100%。没有进一步的义务，也没有保证金追缴。

你不能提前退出仓位。一旦买入，就要持有到到期。

## 卖方风险

你的最大亏损是**你投入的全部 BTC**。如果 BTC 远超你的行权价，买方的支付从你的抵押品中扣除，最多不超过你锁定的金额。要榨干几乎全部抵押品需要极端的行情，大约**超出你行权价 80%**，这在历史上很少见。这种尾部风险正是权利金为你承担的对价，无论结果如何，权利金都归你。

## 结算价格

只有**到期时**的 BTC/USD 价格起作用。期间的行情不影响结算：BTC 可能涨破行权价后又回落，到期时变得毫无价值；也可能整个期限内都低于行权价，最后一刻飙升触发支付。价格来自一个聚合主要交易所的链上预言机。详见[价格预言机](/technical/price-oracle)。

## 自我托管

你的账户与你的钱包绑定。**如果你失去钱包的访问权，你就失去对资金的访问权。** Isometric 不托管你的账户，无法重置，也无法恢复。请使用钱包自带的备份方式备份助记词。

## 协议风险

Isometric 运行在智能合约和价格预言机之上。与任何链上系统一样，存在合约缺陷、预言机故障或链层级事件带来的残余风险。协议是完全有担保的（卖方端没有杠杆，没有保证金追缴），这消除了一大类故障，但并不能消除技术风险。详见[技术](/technical/)章节了解底层机制。

## 哪些**不**是风险

- **强制平仓。** 没有。每个期权在被接受时都完全有担保。
- **保证金追缴。** 没有。你的最差情况在交易那一刻就已固定。
- **对手方违约。** 抵押品在接受时就已锁定，而非承诺。卖方不可能无法交付。
