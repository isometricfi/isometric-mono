# 手续费

两项手续费。两项都会在签名前显示在应用中。

| 端    | 手续费             | 何时收取                                               |
| ----- | ------------------ | ------------------------------------------------------ |
| 卖方  | 权利金的 **5%**    | 买方接受时收取。剩余部分立即记入你的余额。             |
| 买方  | 利润的 **20%**     | 仅当期权处于实值到期时收取。无利润，无手续费。         |

**卖方示例：** 买方以 2% 权利金接受你 1 BTC 的报价（0.02 BTC）。扣除 5% 手续费后，你收到 0.019 BTC。

**买方示例：** 到期时毛利润 0.01 BTC。扣除 20% 手续费后，你收到 0.008 BTC。

没有点差。取消报价不收费。亏损不收费。提款时的比特币网络费另行计算。
