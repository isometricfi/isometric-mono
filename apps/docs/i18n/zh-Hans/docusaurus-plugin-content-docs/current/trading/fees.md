# 手续费

两项手续费。两项都会在签名前显示在应用中。

## 卖方端

买方接受你的报价时，平台从权利金中扣取一小部分百分比。剩余部分立即记入你的可用余额。

示例：买方以 2% 权利金接受你 1 BTC 的报价，支付 0.02 BTC。扣除手续费后，你收到 0.019 BTC。

## 买方端

期权处于实值到期时，平台从你的毛利润中扣取一定百分比，再支付给你。如果期权失效，则不收取手续费，因为没有利润。

示例：到期时毛利润 0.01 BTC。扣除手续费后，你收到 0.008 BTC。

## 仅此而已

没有点差。取消报价不收费。亏损不收费。提款时的比特币网络费另行计算。
