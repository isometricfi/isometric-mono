# 快速开始

本指南将帮助您在几分钟内开始使用 Isometric。

## 开始交易的 3 个步骤

在 Isometric 交易不需要繁琐的注册。只需按照以下三个核心步骤开始：

1. **[设置您的账户](/quick-start/account-setup)**
   - 连接您的钱包
   - 存入 ckBTC
2. **选择您的角色**
   - **如果您想赚取收益**：[卖出期权（卖出备兑看涨期权）](/quick-start/write)
   - **如果您想获得杠杆敞口**：[买入期权](/quick-start/buy)
3. **[管理您的投资组合](/quick-start/portfolio)**
   - 跟踪您的活跃期权
   - 提取结算后的资金

## 什么是 ckBTC？

Isometric 使用 **ckBTC** (Chain-key Bitcoin) 进行所有交易。ckBTC 是在 Internet Computer 网络上的 1:1 比特币映射。

- **快速**：2-5 秒的确认时间
- **廉价**：网络费用极低（约几美分）
- **非托管**：通过阈值 ECDSA (Threshold ECDSA) 密码学直接在协议级别与比特币网络集成

如果您还没有 ckBTC，您可以在应用程序内直接将原生 BTC 转换为 ckBTC。
