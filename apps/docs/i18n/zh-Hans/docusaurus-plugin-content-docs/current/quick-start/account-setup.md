# 账户设置

本指南将引导您完成设置账户、连接钱包以及存入资金以开始交易的整个流程。

## 1. 连接钱包

Isometric 使用 Internet Computer (ICP) 钱包。我们建议使用以下钱包：

- **Bitfinity Wallet** (浏览器扩展程序)
- **Plug Wallet** (浏览器扩展程序)
- **Internet Identity** (硬件密钥或生物识别)

### 如何连接：
1. 点击 Isometric 应用程序右上角的 **"Connect Wallet"**。
2. 从列表中选择您喜欢的钱包。
3. 在弹出的窗口中审批连接请求。

## 2. 理解您的余额

连接后，您会看到两种余额：

- **Available Balance**：可以立即用于购买或卖出期权的资金。
- **Locked Balance**：当前被锁定在活跃期权合约中作为抵押品的资金。

## 3. 存入资金 (ckBTC)

Isometric 使用 **ckBTC** 进行交易。要存入资金，您有两种选择：

### 选项 A：存入原生 BTC
如果您钱包中有原生比特币 (BTC)：
1. 进入 **Deposit** 页面。
2. 复制您的 **ckBTC Minting Address**。
3. 从您的外部钱包发送 BTC 到此地址。
4. 几分钟后，您的 BTC 将被自动转换为 ckBTC 并显示在您的余额中。

### 选项 B：存入 ckBTC
如果您已拥有 ckBTC：
1. 确保您的 ckBTC 位于连接的钱包地址中。
2. 资金将直接显示在应用程序的 **Available Balance** 中。

:::warning 最小存款额
虽然平台没有硬性的最小存款限制，但建议至少存入 **0.0005 BTC**，以便能够支付最小的期权头寸和网络费用。
:::

## 4. 提取资金

您可以随时提取您的可用余额：
1. 点击 **"Withdraw"**。
2. 输入提款金额和您的目标地址。
3. 确认交易。

:::info 提取原生 BTC
如果您提回原生比特币地址，系统会自动将您的 ckBTC 转换回 BTC 并在比特币网络上发送给您。
:::
