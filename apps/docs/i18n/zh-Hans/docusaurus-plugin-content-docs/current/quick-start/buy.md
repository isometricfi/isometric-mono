# 买入 (Buy)

**买入 (Buy)** 页面允许您购买看涨期权，以获得对比特币价格波动的杠杆敞口。

## 什么是买入看涨期权？

当您**买入看涨期权**时，您：

1. **预先支付权利金** - 这是您的最大亏损额
2. **获得获利权** - 如果 BTC 上涨到行权价以上
3. **接收自动支付** - 无需手动行权
4. **风险仅限于权利金** - 您的下行风险是有限的

### 简单示例

- BTC 当前价格为 **$100,000**
- 您买入一个看涨期权，条款如下：
  - **行权价**：$110,000 (高于当前价格 10%)
  - **权利金**：0.003 BTC (约 $300)
  - **到期时间**：7 天
- **到期时**：
  - 如果 BTC 是 **$132,000**：您获利了！您收到约 0.05 BTC (约 $6,600) - 扣除您的 0.003 BTC 权利金 = 约 $6,300 净利润 ✅
  - 如果 BTC 是 **$105,000**：期权到期无价值，您损失了 0.003 BTC 的权利金 ❌

:::tip
买入看涨期权是一种在无需买入全额 BTC 的情况下获得杠杆敞口的方法。您的风险仅限于您支付的权利金。
:::

## 前提条件

- [已创建并存入资金的账户](/quick-start/account-setup)
- 足够的**可用余额 (Available balance)** 来支付权利金 + 转账费用

## 第 1 步：导航至买入期权

1. 进入 Isometric Web 应用程序。
2. 在导航栏点击 **"Buy Options"** 或 **"Trade"**。
3. 您将看到来自卖方的可用订单。

## 第 2 步：浏览可用订单

平台会向您展示按以下方式分组的**开启状态订单 (Open offers)**：

- **根据到期时间** (例如 1 天、7 天、14 天)
- **根据行权价** (例如 高于当前 BTC 价格 +5%、+10%、+15%)
- **根据权利金** (例如 0.5%、1%、2%)

### 理解订单列表

每个订单显示：

- **Writer (卖方)**：谁在卖出期权 (匿名 Principal ID)
- **Quantity Available (可用数量)**：有多少 BTC 抵押品可用
- **Strike (行权价)**：您获利所需的 BTC 价格 (相对于当前价格的 % )
- **Premium (权利金)**：您需要支付的费用 (以数量的 % 计)
- **Expiry (到期时间)**：期权何时结算

:::info
以美元计价的行权价在**您接受订单时**锁定，基于那一刻的当前 BTC 价格。如果 BTC 是 10万，而您选择了 +10%，则行权价锁定为 11万。
:::

## 第 3 步：选择一个订单

点击一个订单以查看详情并接受它。

### 选择合适的期权

考虑以下因素：

1. **行权价**：您认为 BTC 会涨多少？
   - **较低的行权价** (+5%) = 更容易获利，但权利金较高
   - **较高的行权价** (+15%) = 权利金更便宜，但 BTC 必须涨得更多

2. **到期时间**：您想要多长时间的敞口？
   - **较短** (1 天) = BTC 波动的时间较少，权利金较便宜
   - **较长** (14 天) = BTC 波动的时间较多，权利金较昂贵

3. **权利金**：您愿意承担多少风险？
   - 记住：权利金是您的最大亏损额

### 部分成交 (Partial Fills)

如果您不需要全部数量，您可以**买入订单的一部分**：

- 卖方提供：1.0 BTC
- 您买入：0.2 BTC
- 剩余部分：0.8 BTC 仍可供其他买方购买

## 第 4 步：输入数量

1. 输入您想要的 BTC 敞口数量。
2. 平台会自动计算：
   - **您将支付的权利金**
   - **转账费用** (少量的 ckBTC 网络费用)
   - **总成本**

:::warning 检查您的余额
请确保您的可用余额足以支付总成本 (权利金 + 费用)。
:::

## 第 5 步：查看并确认

在接受之前请确认：

- **行权价** (在接受时锁定为美元)
- **权利金** (您现在支付的金额)
- **到期时间** (何时进行结算)
- **最大盈利** (如果 BTC 涨到无限大)
- **最大亏损** (权利金)

## 第 6 步：签名并接受

1. 点击 **"Buy Option"** 或 **"Accept Offer"**。
2. 在您的钱包中查看签名消息。
3. 签名交易。
4. 您的期权现已开启！

### 接下来会发生什么？

1. **权利金已转账** - 从您的余额转给卖方 (扣除平台费用)。
2. **抵押品被锁定** - 卖方的 BTC 将被锁定直至到期。
3. **活跃期权已创建** - 您可以在投资组合中跟踪它。
4. **自动结算** - 到期时，平台会自动进行结算。

## 管理您的期权

### 查看您的活跃期权

进入 **"My Options"** 或 **"Portfolio"** 查看：

- **Option ID**：唯一标识符
- **Strike price**：BTC 必须超过的价格
- **Entry price**：您买入时的 BTC 价格
- **Current BTC price**：实时价格
- **Expiry**：何时结算
- **Status**：活跃 (Active)、已结算 (Settled) 等

### 我可以提前卖出我的期权吗？

**当前的 MVP 版本暂不支持。** 期权必须持有直至到期。未来可能会加入二手市场交易功能。

## 到期时：会发生什么？

平台会自动结算您的期权：

### 如果为虚值 (BTC 低于行权价)

- **您获得**：无 (期权到期无价值)
- **您损失**：您支付的权利金
- **卖方保留**：抵押品 + 权利金

**示例：**
- 行权价：$110k
- 到期价格：$105k
- 您的损失：已支付的权利金 (例如 0.003 BTC)

### 如果为实值 (BTC 高于行权价)

- **您获得**：等于内含价值的支付额
- **您获利**：支付额减去权利金
- **卖方损失**：从其抵押品中支付的金额

**示例：**
- 行权价：$110k
- 到期价格：$132k
- 数量：0.3 BTC
- **内含价值**：`((132k - 110k) / 132k) × 0.3 = 0.05 BTC`
- **您的收益**：0.05 BTC
- **您的利润**：0.05 BTC - 0.003 BTC 权利金 = 0.047 BTC (约 $6,200)

:::tip
收益是以 BTC 计价计算的，因此您收到的是 BTC 而不是美元。该公式利用结算价格将美元计的内含价值转换回 BTC。
:::

## 理解收益 (Payoff)

### 损益平衡点 (Breakeven Point)

您的**损益平衡点**是行权价加上权利金成本 (以美元计)。

**示例：**
- 行权价：$110k
- 权利金：0.003 BTC (买入时价值约 $300)
- 损益平衡点：约 $110,300

如果到期时 BTC 高于您的损益平衡点，您就会获利。

### 最大利润

理论上**无限**。BTC 涨得越高，您的利润就越多。

### 最大亏损

**仅限于您支付的权利金**。即使 BTC 跌至 0，您也只损失权利金。

## 费用

当您买入期权时，您支付：

- **权利金** (付给卖方)
- **平台费用** (权利金的一个小百分比，例如 5%)
- **转账费用** (用于交易的 ckBTC 网络费用)

详见 [费用结构](/architecture/fees)。

## 成功买入的技巧

1. **从小额开始** - 先在小头寸上进行测试
2. **不要过度加杠杆** - 只投入您能承受损失的部分
3. **选择现实的行权价** - 虚值太远 = 获利概率太低
4. **监控到期** - 期权自动结算，无需任何操作
5. **了解您的最大损失** - 始终是权利金

## 常见问题

### 我可以提前行权吗？

不可以。所有期权均为**欧式期权**，意味着只能在到期时结算，不能提前结算。

### 如果预言机价格错误怎么办？

平台使用 ICP 汇率分片（exchange rate canister），它聚合了多个来源的数据。如果您认为有问题，可以向社区提出，但结算结果通常是最终的。

### 我可以一次买入多个期权吗？

可以！您可以在一笔交易中接受多个订单（称为“缝合” (stitching)）。这让您可以从多个卖方那里构建更大的头寸。

### 如果我没有足够的余额会怎样？

交易将失败。在接受订单前，请确保您的可用余额足以支付总成本 (权利金 + 费用)。

### 到期时我需要做些什么吗？

不需要。结算是**完全自动的**。如果您的期权处于实值状态，您将自动收到收益。如果是虚值，它将到期无价值。
