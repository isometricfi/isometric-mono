# 卖出 (Write)

**卖出 (Write)** 页面允许您通过为您持有的比特币提供备兑看涨期权来赚取权利金收入。

## 什么是卖出备兑看涨期权？

当您**卖出备兑看涨期权**时，您：

1. **锁定 BTC 作为抵押品** - 您的 BTC 由智能合约持有
2. **设定您的条款** - 选择行权价、权利金和到期时间
3. **赚取权利金** - 买方预先向您支付权利金以接受您的卖单
4. **如果为虚值 (OTM) 则保留抵押品** - 如果比特币在到期时低于行权价，您将保留您的抵押品以及收取的权利金

### 简单示例

- 您锁定 **0.1 BTC** 作为抵押品
- 您提供一个看涨期权订单，条款如下：
  - **行权价**：高于当前 BTC 价格 10% (例如，如果 BTC 是 10万，行权价为 11万)
  - **权利金**：1% (0.001 BTC)
  - **到期时间**：7 天
- 一位买方接受该订单并立即向您支付 **0.001 BTC**
- **到期时**：
  - 如果 BTC **低于 $110,000**：您保留您的 0.1 BTC + 0.001 BTC 权利金 ✅
  - 如果 BTC **高于 $110,000**：买方从您的抵押品中获得收益，您保留收取的权利金

:::tip
卖出备兑看涨期权是一种在您本来就打算持有的 BTC 上赚取收入的方法。它在您预期 BTC 保持相对平稳或小幅上涨时效果最佳。
:::

## 前提条件

- [已创建并存入资金的账户](/quick-start/account-setup)
- 足够的**可用余额 (Available balance)** 来支付抵押品金额

## 第 1 步：导航至卖出期权

1. 进入 Isometric Web 应用程序。
2. 在导航栏点击 **"Write Options"** 或 **"Sell"**。
3. 您将看到期权创建表单。

## 第 2 步：选择您的参数

您将从**标准化菜单**中进行选择（不是自由输入）。这确保了流动性，并使买方更容易找到您的报价。

### 资产 (Asset)

目前仅支持 **BTC/USD 看涨期权**。

### 行权价 (Strike Price)

行权价表示为**高于当前 BTC 价格的百分比**。

**可用行权价** (示例)：
- +5% (轻微价外)
- +10% (中度价外)
- +15% (深度价外)

**行权价越高** = 被行权的概率越低 = 权利金较低，但对您来说更安全

:::info 行权价锁定原理
以美元计价的行权价在**买方接受您的订单时**锁定，而不是在您创建订单时。如果买方接受时 BTC 是 10万，而您选择了 +10%，则行权价锁定为 11万。
:::

### 权利金 (Premium)

权利金是买方预先支付给您的费用，表示为**抵押品金额的百分比**。

**可用权利金** (示例)：
- 0.5% (较低的权利金，更容易吸引买方)
- 1.0%
- 2.0%
- 5.0% (较高的权利金，较难吸引买方)

**权利金越高** = 您的收入越高，但买方可能更倾向于更便宜的选择

### 到期时间 / 期限 (Expiry / Duration)

选择期权的持续时间：

**可用期限** (示例)：
- 1 天
- 7 天
- 14 天

**期限越长** = BTC 波动的时间越多，通常权利金更高

### 数量 (Quantity)

您想要锁定作为抵押品的 BTC 数量。

**最小值**：由平台设定 (例如 0.005 BTC)
**最大值**：您的可用余额

:::warning
当您创建一个订单时，您的抵押品还**没有**被锁定。它仅在买方接受时锁定。但是，您必须拥有足够的可用余额。
:::

## 第 3 步：签名并提交

1. 点击 **"Create Offer"**。
2. 在您的钱包中查看签名消息。
3. 签名交易。
4. 您的订单现已上线！

## 第 4 步：等待买方

您的订单将出现在 **Open Offers** 列表中供买方浏览。

### 当买方接受时会发生什么？

1. **抵押品被锁定** - 您的 BTC 从“可用”变为“锁定”。
2. **权利金已支付** - 您立即收到权利金 (扣除少量平台费用)。
3. **活跃期权已创建** - 期权现已激活，并将在到期时结算。

### 部分成交 (Partial Fills)

如果启用了部分成交，买方可以接受**您订单的一部分**。例如：
- 您提供 1.0 BTC。
- 买方购买 0.3 BTC。
- 您的订单保持开启状态，余下 0.7 BTC。

## 管理您的订单

### 查看您的订单

进入 **"My Offers"** 查看：
- **Open**：等待买方的订单
- **Partially Filled**：部分被接受的订单
- **Filled**：已完全被接受的订单
- **Cancelled**：您已取消的订单

### 取消订单

您可以在订单**被接受之前**取消它：

1. 进入 **"My Offers"**。
2. 找到您想取消的订单。
3. 点击 **"Cancel"**。
4. 签名取消消息。

:::info
订单被接受 (即使是部分接受) 后，您将无法取消。一旦被接受，该期权必须运行直至到期。
:::

## 到期时：会发生什么？

平台会自动结算您的期权：

### 如果为虚值 (BTC 低于行权价)

- **您保留**：您的全部抵押品 + 权利金
- **买方获得**：无 (期权到期无价值)
- **您的抵押品解锁**：可用于提现或创建新订单

### 如果为实值 (BTC 高于行权价)

- **您保留**：权利金
- **买方获得**：从您的抵押品中支付收益 (即内含价值)
- **您保留**：支付后的剩余抵押品

**示例：**
- 行权价：$110k
- 到期价格：$132k
- 抵押品：0.3 BTC
- 支付给买方：~0.05 BTC (以 BTC 计价的内含价值)
- 您保留：0.25 BTC + 权利金

## 费用

- **权利金费用**：您赚取的权利金的一个百分比 (5%)

详见 [费用结构](/architecture/fees)。

## 成功卖出的技巧

1. **从小额开始** - 先用少量金额进行测试
2. **选择现实的行权价** - 虚值太远 = 权利金太低，行权价太近 = 风险太高
3. **监控市场** - 根据 BTC 波动性调整您的挂单
4. **分散到期日** - 不要把所有抵押品都放在同一个到期日
5. **了解您的风险** - 您在行权价处封顶了您的上行空间

## 常见问题

### 我可以在到期前提取抵押品吗？

不可以。一旦订单被接受，您的抵押品将被锁定，直至到期或结算。

### 如果没有买方接受我的订单怎么办？

您的订单将根据您设置的“有效期”过期。之后您可以创建一个新订单或调整您的条款。

### 创建订单后可以修改吗？

不可以。您必须取消订单并使用更新后的条款创建一个新订单。

### 如果预言机出现故障会怎样？

结算将延迟，直到预言机提供有效的价格。您的抵押品在结算完成前将保持锁定。
